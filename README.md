# EventTix - Event Ticket Booking Application

A full-stack Event Ticket Booking Application built with React (Vite), Node.js, Express, and MongoDB.

## Features
- **User Authentication**: Secure register and login system using password hashing (`bcrypt`).
- **Profile Management**: View and edit user profiles (including phone number and date of birth).
- **Admin Dashboard**: Event CRUD operations with poster upload (via Multer).
- **Ticket Booking**: User booking system with quota verification and stock deduction.

## Tech Stack
- **Frontend**: React (Vite), Tailwind CSS
- **Backend**: Node.js, Express.js, MongoDB (Mongoose)
- **File Upload**: Multer
- **HTTP Client**: Axios
- **Notifications**: React Hot Toast
